# Portfolio

My personal portfolio website. It is meant to show who I am, what I've done, and ways to get in touch, hopefully in a more interesting presentation than my LinkedIn profile or resume.

The site is built with [Astro](https://astro.build/) and TypeScript.

## Development

Install dependencies, then start the dev server:

```sh
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

| Command | Action |
| --- | --- |
| `npm run dev` | Start the local dev server |
| `npm run build` | Build the production site to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run check` | Type-check the project |
