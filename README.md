# Portfolio

A personal portfolio website, currently in development. It is meant to show who I am, a few pieces of work worth looking at, and a way to get in touch.

## Stack

The site is built with [Astro](https://astro.build/) and TypeScript.

## Development

Install dependencies, then start the dev server:

```sh
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

| Command | Action |
| --- | --- |
| `npm run dev` | Start the local dev server |
| `npm run build` | Build the production site to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run check` | Type-check the project |

## Status

The home page introduces me, a few selected projects, a shorter list of other work, music playlists, and contact links. Three projects have a longer writeup.
